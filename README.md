# Student Performance Dashboard

A Data Science mini project developed using Python, Pandas and Streamlit.

## Features

* Student performance analysis
* Average marks calculation
* Attendance analysis
* Top performer identification
* Interactive student selection
* Data visualization dashboard

## Technologies Used

* Python
* Pandas
* Streamlit

## Project Outcome

This dashboard helps analyze student academic performance through interactive visualizations and statistical insights.
